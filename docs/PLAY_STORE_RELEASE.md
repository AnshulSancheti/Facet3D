# Google Play release preparation

This repository is not declared Play-ready. Native SDK runtime, physical performance, forms, policy declarations and developer details require verification before release. No publication or paid account creation is authorized.

Requirements checked 2026-10-22 against [Google Play target API requirements](https://support.google.com/googleplay/android-developer/answer/11926878): new phone apps/updates require target API36 or later after2026-08-31. Presets target36, minimum24 (plugin requirement), ARM64 only, portrait, versionCode1, versionName0.1.0. Replace `com.yourstudio.facetescape3d` with the studio-owned package before initial publication. Increment versionCode for every uploaded update. Recheck requirements on submission day.

[Android's16KB guidance](https://developer.android.com/guide/practices/page-sizes) requires auditing every native library, not only Godot. `tools/audit_android.py APK` checks ELF LOAD alignment for every packaged64-bit shared library and invokes build-tools36 zipalign `-c -P16 4`. Static alignment passing does not prove runtime compatibility. Test on an authorized16KB physical device before release. For a release AAB, use official bundletool to dump config and require `PAGE_ALIGNMENT_16K`, generate APK sets and audit resulting APKs too. The APK audit cannot validate an unbuilt AAB.

Complete `release/checklists/RELEASE.md`. Provide an actual privacy-policy URL and support contact. Review target audience and Families requirements without inferring an age category from art. Declare contains-ads accurately if ads are enabled in the shipping build. Complete content rating, Data Safety, ads/advertising-ID declarations, app access (no account required), store text, screenshots from the actual game, adaptive icon, feature graphic and original-asset license inventory.

Use Google Play App Signing and a separately authorized upload key. Test signed AAB through internal testing and applicable closed-testing requirements for the actual developer account. Review Android vitals/pre-launch reports, crashes, ANRs, accessibility, touch gestures, cutouts, offline saves, upgrade/corruption recovery and battery behavior. Release signing and uploading remain owner actions; nothing has been published.

Debug build evidence is in `release/checklists/android/BUILD_AUDIT.md`. It passed APK signature verification, target36 manifest inspection and all-library16KB static alignment. Release remains blocked on native runtime tests, signing/owner information, inherited SDK-permission review and upgrading/revalidating the official template's AGP8.6.1 against API36's supported minimum8.9.1. See [Android's tooling matrix](https://developer.android.com/build/releases/about-agp). No signed release AAB exists.
